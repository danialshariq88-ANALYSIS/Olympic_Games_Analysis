# Olympic_Games_Analysis

Analyzed Olympic Games data using Python, Pandas, and Jupyter Notebook. Explored medal distribution by gender and country, Olympic participation trends over time, and athletes’ age distributions. Used data cleaning, grouping, and statistical analysis to identify patterns and insights in Olympic history.
